# Decline-of-War---Regional

Replication materials for Spagat, M. and W. Thompson (2026), "The Decline of War Question: A Comparative Regional Perspective," Peace Economics, Peace Science and Public Policy, https://doi.org/10.1515/peps-2026-0047.

Contents. ProjectMars_plus_GiblerMiller_final.xlsx: the data (sheet data), with a construction sheet documenting how it was built. main_analysis.R: reproduces all tables and figures. Appendix_regional_classification.docx: the regional coding scheme.

To run. Place the data file and script in the same folder and run main_analysis.R in R. Required packages: readxl, dplyr, ggplot2, gt, AER.
